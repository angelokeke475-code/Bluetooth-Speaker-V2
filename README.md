# Bluetooth-Speaker-V2
A cleaner, sleeker Bluetooth speaker using parts from the one I built in engineering class.
## Description
This is a redesign of the Bluetooth speaker I made in my engineering class. The original speaker was made from plywood and was powered by a lipo battery system. I decided to 3D print the enclosure this time to give it a sleeker design, and went with a USB Micro-B connection for direct power since this one is meant to sit permanently at my desk (and the components for the lipo system weren't consistent). https://hallco.onshape.com/documents/a0346f85c55b197866ffa839/w/45844834e756e30cdf49984f/e/b82fa72779c787932b57bcae?renderMode=0&uiState=6afc369c0519ccb0693a1e33

## Getting Started

### Dependencies
- Access to a 3D Printer and PLA Filament (any color you want)
- Ability to solder (if the speaker comes without wires)
- Tools to screw in M3 screws
- A USB Micro-B Cable (linked in BOM if not owned)

### Installing
- Download the CAD files of the repo to print them for the speaker
### Building Project
- Download all CAD files in this repo
- Slice all of them on whatever 3D printer software you use
- Make sure it's PLA at 15% infill (you can even put ironing on the top layers of the front plate and box if you want to)
- Print all parts
- Attach the speaker to the BT module (you might have to solder wires to do so)
- Slot the speaker and BT Module through the speaker plate and attach the speaker with M3 screws
- Snap fit that component into the speaker box
- Snap fit the front plate into the speaker box
- Plug in the speaker and you're done :)
### Wiring Diagram 
- Here's a crude wiring diagram of the speaker
- The AC power source (the circle thingy) represents plugging the micro b cable into the wall
- The best thing you can do is use one of the yellow and blue wire sets since it has the plug for the Bluetooth module at the end
- If you do that, you'll only have to solder each wire to one of the terminal ends of the speaker (I find that order/orientation doesn't matter just make sure each wire is connected well)
